# StoryCraft Skills for Gemini & Antigravity

StoryCraft equips your agent with 23 professional fiction writing and novel architecture skills.

## Core Rules

1. Before generating chapters or plotting scenes, check for existing project state in `story-state.md` and canon in `story-bible.md`.
2. Activate `using-storycraft` or `novel-brainstorming` when initiating new projects or diagnosing creative roadblocks. Run `/using-storycraft pipeline` for full autonomous end-to-end execution with hard-gate approvals.
3. For ultra-long serials (500–5,000+ chapters), maintain strict power-tier ceilings, character location status, and open-loop ledgers via `novel-mega-serial-architect`.
4. Eliminate sensory filter words ("saw", "felt", "heard", "wondered") and maintain Deep Point of View (Deep POV) across all narrative drafting.
5. Audit chapters, batches, arcs, and volumes with brutal developmental honesty across 40 craft vectors and 15 benchmark comps via `novel-master-reviewer`.
6. Enforce physical wound, inventory, and timeline continuity via `novel-continuity-checker`.
7. Update `story-state.md` and generate the Next Session Bootstrap Prompt upon concluding any writing task.
