# Installing StoryCraft Skills in OpenCode

To install StoryCraft Skills in OpenCode:

1. Clone or copy this repository into your workspace or skills directory:
   ```bash
   git clone https://github.com/leapwithluvi/storycraft-skills.git
   ```
2. Copy `dist/AGENTS.md` to your OpenCode root as `AGENTS.md`.
3. Copy `dist/codex/` into your OpenCode project directory.
4. Verify by asking your OpenCode assistant: *"What novel skills are available?"*
